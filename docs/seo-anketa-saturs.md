### 2.1. Google Search Console *(obligāts)*
Kāpēc: redzu, pēc kādiem vaicājumiem jūs atrod, un varu parādīt, kas mainījies pirms un pēc izmaiņām.
1. Atveriet search.google.com/search-console un izvēlieties savu domēnu.
2. Kreisajā izvēlnē: Settings → Users and permissions → Add user.
3. Pievienojiet abas adreses, tiesības **Full**:
   - `rois-auditor@rois-1735811972671.iam.gserviceaccount.com`
   - `gatis.design@gmail.com`
Ja Search Console nav: atzīmējiet „Vajag palīdzību”, izveidosim kopā (jāpievieno DNS
ieraksts, tas aizņem ap 10 minūtēm).

### 2.2. Google Analytics 4
Kāpēc: pieprasījumi un pirkumi pirms un pēc izmaiņām.
1. analytics.google.com → apakšā kreisajā pusē Admin (zobrats).
2. Property → Property access management → "+" → Add users.
3. Abas adreses, loma **Viewer**. Ja jāiestata arī konversijas, `gatis.design@gmail.com` - **Editor**.

### 2.3. Mājaslapas administrācija
Kāpēc: virsraksti, apraksti, strukturētie dati un pāradresācijas. Lūdzu, izveidojiet man
atsevišķu lietotāju, nevis dodiet savu personīgo kontu.
- **WordPress:** Users → Add New → e-pasts `gatis.design@gmail.com`, loma Administrator
  (vai Editor, ja SEO spraudnim ir atsevišķas tiesības).
- **Shopify:** Settings → Users → Add users (e-pasts `gatis.design@gmail.com`),
  vai apstipriniet sadarbības partnera pieprasījumu, ko nosūtīšu.
- **Cita sistēma:** ierakstiet, kāda tā ir un kā tajā pievieno lietotāju.
Lauks: CMS sistēma *(izvēle: WordPress / Shopify / Wix / Webflow / Cita / Nezinu)*

### 2.4. Google Tag Manager *(tikai tad, ja jāiestata mērīšana)*
1. tagmanager.google.com → Admin → User Management → "+" → Add users.
2. Abas adreses, konteinera tiesības **Publish**.

### 2.5. Bing Webmaster Tools
Kāpēc: ChatGPT un Copilot meklēšana balstās uz Bing indeksu. Bez šī rīka šo daļu nevar izmērīt.
1. bing.com/webmasters → pieslēdzieties ar Microsoft vai Google kontu.
2. Izvēlieties "Import from Google Search Console" - vietne pievienojas 2 minūtēs.
3. Settings → User management → Add user → `gatis.design@gmail.com`, loma **Administrator**.

### 2.6. Google Business Profile *(tikai tad, ja jums ir veikals vai birojs vai apkalpojat noteiktu reģionu)*
1. business.google.com → jūsu profils → Business Profile settings → People and access → Add.
2. `gatis.design@gmail.com`, loma **Manager**.

## 4. Par nozari

Ievads: Šīs atbildes vajadzīgas, pirms rakstu pirmo teikumu jūsu lapai. Bez tām teksts
būs tehniski pareizs, bet nozares cilvēks tajā pamanīs kļūdas.

1. Kurus zīmolus jūs pārdodat, un kas ir katra ražotājs vai mātes uzņēmums?
2. Ko pircēji visbiežāk jautā pa telefonu pirms pirkuma? Pieci biežākie jautājumi.
3. Ko par jums nedrīkst apgalvot? (Piemēram: ražotājs vai izplatītājs, garantijas, sertifikāti.)
4. Trīs galvenie konkurenti. Vai kāds no tiem ir arī jūsu partneris vai pārdevējs?
5. Kādi nozares termini vai saīsinājumi jūsu tekstos pircējam būtu jāpaskaidro?
6. Vienā teikumā: ko jūs darāt, saviem vārdiem.
